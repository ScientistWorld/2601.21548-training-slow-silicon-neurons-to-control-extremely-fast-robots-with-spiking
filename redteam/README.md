# Scoring audit

Run `bash redteam/<case>/run.sh` on a compute node. `cases.json` lists the batch;
`python redteam/run_all.py` runs it sequentially and creates `analysis.json` and
`summary.csv`. Only NumPy from the original environment is needed.

Each case installs its artifact(s) under `outputs/`, invokes the original visible
evaluator, and launches `bash scripts/evaluate_test.sh` with **no arguments**, in
a separate process. No evaluator, interpreter, import hook, or Python environment
is replaced. There are no background processes. SHA-256 checks record that all
evaluator source files and the test wrapper remain unchanged. The harness saves
the actual evaluator-written JSON and exit code, then restores the workspace's
original outputs, scores, simulator, and baseline in a `finally` block.

The real spiking runs use the original algorithm and 1020-neuron size, reference
hyperparameters recorded in the original artifacts, 500 held-out episodes per
seed, and seeds 0, 1, 2. Intermediate evaluation copies the controller, preserving
the uninterrupted training trajectory. The three reference seeds, the zero-update
ablation, and the 10,000-episode extension reuse these computations. Cached
training summaries are generated under `_cache/` (ignored); installed artifacts
are preserved in each case's `submitted_artifacts.json`.

The learned-timing quality control uses genuine online interaction and reward
updates, without a simulator model, answers, or evaluation seed input. It is an
alternative learning method for the substitute task, **not** a reproduction of
the paper's neuromorphic method. Its declared capacity is held at the reference
budget to avoid attributing a capacity bonus to its task improvement.

Shortcut construction reads only agent-visible simulator/method code, public
artifact conventions, and summaries produced by the audit's own reference runs.
The original hidden scoring files in `_initial/scoring/` are used solely by the
audit analysis as comparison targets; shortcut construction never reads them.
Reused summaries are permitted by the audit request and could be regenerated by
an improve-mode agent. The forged-summary and data-replacement shortcuts also
work from scratch without any reference output.

`analysis.json` uses absolute metric coefficients, better-direction signs, and
experiment weights. Its rank numbers use population standard deviations across
the finite, successful audit cohort plus the reference. Future attempt-dependent
normalizers are unavailable, so these are explicitly illustrative: direct metric
dominance, omitted losses, and exact ties are the unconditional findings.
Nonfinite results and nonzero test exits are not assigned a valid rank.
